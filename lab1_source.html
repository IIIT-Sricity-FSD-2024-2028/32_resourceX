FDFED M2026
Lab 1: Existing Application Analysis & React Planning

Objective

Purpose:. Analyze your existing multi-page application and identify the parts that will need to be redesigned/reimplemented using React during this semester.

This lab focuses on analysis and planning, not implementation.

Important:

Do NOT implement React in this lab. Do not rebuild your pages using React yet.

Your analysis from this lab will be used as the starting point for your React implementation in the upcoming labs.

What You Will Do

  • Understand your existing application flow
  • Identify repeated UI elements
  • Identify dynamic behaviour
  • Analyze your existing JavaScript
  • Analyze the NestJS APIs used by your frontend
  • Identify problems in the existing frontend
  • Identify where React could improve the application
  • Select one feature/page for the first React conversion

Task 0: Understand Your Application Flow

Activity: Explore your existing application

First, use your application as a normal user. Do not start by looking at the source code.

Identify the entry page, main pages, important user workflows, where the user enters data, where the user receives or views data, and which parts of the application use backend data.

Submit

Prepare a simple application-flow diagram.

Task 1: Identify Repeated UI

Inspect all pages of your existing application. Identify UI elements that appear on multiple pages, are repeated many times on the same page, or have the same or similar structure.

Task 2: Identify Dynamic Behaviour

Interact with your application and observe what changes.

Ask: "What changes when the user does something?"

Consider user actions such as clicking a button, entering text, searching, selecting an option, submitting a form, adding or removing an item, logging in or logging out, and opening or closing a modal or menu.

Submit

Prepare a table and submit the list as shown below.

Page / Feature User Action What Changes?
Example: Products Enter search text Product list changes
React connection:

These behaviours will later help you understand React events and state.

Possible Areas to Investigate

  • Repeated HTML
  • Repeated JavaScript
  • Manual DOM manipulation
  • Repeated navbar/header/footer code
  • Repeated card/table structures
  • Difficult UI updates
  • Duplicate event handling
  • Large JavaScript files
  • Difficult-to-maintain frontend logic
